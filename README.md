# CardWise – Customer Segmentation (K-Means)

Streamlit app that segments credit-card customers with K-Means (k=4, random_state=42).

Sections: data loading & missing values · EDA (correlation, histograms, scatter, boxplots) · preprocessing (feature selection, log1p + StandardScaler) · Elbow + Silhouette · KMeans profiling · business recommendations.

Run locally:
```
pip install -r requirements.txt
streamlit run app.py
```
